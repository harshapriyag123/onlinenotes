# R2017 IT Materials

Use this folder to organize Anna University IT Regulation 2017 materials semester-wise.

## Structure
- semester-*/notes: unit notes and summary sheets
- semester-*/lab: lab record notes, viva Q&A, code snippets
- semester-*/pyq: previous year question papers and self-prepared answers
- semester-*/interview: core concept notes, coding interview prep, HR notes
- SEMESTER_RESOURCE_MAP.md: semester-wise open link guide and study direction

## Naming Convention
- subject-unit-topic.pdf
- subject-exam-year-month.pdf
- subject-viva-questions.md
