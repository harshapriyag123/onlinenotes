# R2017 IT Semester Resource Map (Open)

Use this as a practical semester navigation guide.
Always verify final subject order/codes with official Anna University syllabus documents.

## Semester 1 Focus
- Foundations: mathematics, basic programming, problem solving.
- Use:
  - NPTEL: https://nptel.ac.in
  - MIT OCW intro CS: https://ocw.mit.edu
  - DSA basics: https://www.geeksforgeeks.org/dsa/dsa-tutorial-learn-data-structures-and-algorithms/

## Semester 2 Focus
- Programming depth, discrete math, data handling basics.
- Use:
  - NPTEL: https://nptel.ac.in
  - MIT OCW: https://ocw.mit.edu
  - GFG CS basics: https://www.geeksforgeeks.org/gate/gate-exam-tutorial/

## Semester 3 Focus
- Data structures, database basics, system fundamentals.
- Use:
  - DBMS track: https://www.geeksforgeeks.org/dbms/dbms/
  - OS track: https://www.geeksforgeeks.org/operating-systems/operating-systems/
  - NPTEL core courses: https://nptel.ac.in

## Semester 4 Focus
- OOP, DBMS depth, OS, algorithms and theory.
- Use:
  - DBMS: https://www.geeksforgeeks.org/dbms/dbms/
  - OS: https://www.geeksforgeeks.org/operating-systems/operating-systems/
  - DSA: https://www.geeksforgeeks.org/dsa/dsa-tutorial-learn-data-structures-and-algorithms/

## Semester 5 Focus
- Networks, TOC/compiler foundations, software subjects.
- Use:
  - CN: https://www.geeksforgeeks.org/computer-networks/computer-network-tutorials/
  - TOC: https://www.geeksforgeeks.org/theory-of-computation/theory-of-computation-automata-tutorials/
  - NPTEL: https://nptel.ac.in

## Semester 6 Focus
- Compiler, AI/data, software engineering, electives.
- Use:
  - Compiler design: https://www.geeksforgeeks.org/compiler-design/compiler-design-tutorials/
  - MIT OCW AI/ML related tracks: https://ocw.mit.edu
  - Project ideas: https://www.geeksforgeeks.org/projects/

## Semester 7 Focus
- Electives, mini/major project, placement prep phase 1.
- Use:
  - OSSU open curriculum (project depth): https://github.com/ossu/computer-science
  - Coding interview roadmap: https://github.com/jwasham/coding-interview-university
  - GeeksforGeeks Interview Corner (Free): https://www.geeksforgeeks.org/interview-prep/interview-corner/

## Semester 8 Focus
- Final project completion, placements, interview revision.
- Use:
  - takeUforward: https://takeuforward.org
  - Coding Interview University: https://github.com/jwasham/coding-interview-university
  - Free books and references: https://github.com/EbookFoundation/free-programming-books

- Add only self-prepared answers and topic tags.
