# Online Notes Portal

A simple online notes portal with a login page.

## Login Credentials

Use the following credentials to log in:

| Field    | Value      |
|----------|------------|
| Username | `user`     |
| Password | `password` |

## Usage

1. Open `index.html` in your browser.
2. Enter the username and password from the table above.
3. Click **Let me in** to access the notes portal.
